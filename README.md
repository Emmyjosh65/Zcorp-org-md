## INSTALL

npm install

## START

npm start

## PTERODACTYL

Use Node.js 20 or newer.

Startup command:

npm start

## ENVIRONMENT

Create .env:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

GEMINI_API_KEY=YOUR_GEMINI_API_KEY

Never upload .env to GitHub.
